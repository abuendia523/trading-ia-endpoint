# Aviso de privacidad — Trading IA

**Trading IA** es una app privada para familia y amigos, con fines educativos. No tiene cuentas de usuario, no muestra publicidad y no rastrea a nadie.

## Qué se guarda en tu teléfono
El historial de tus análisis y, si decides agregarla, tu propia clave de API (en el Keychain del iPhone). Puedes borrarlos en Ajustes → «Borrar todo».

## Qué recibe el servidor
El símbolo que quieres analizar y un identificador aleatorio del dispositivo, que sirve para repartir el cupo diario. El resultado se conserva hasta 72 horas para que puedas verlo si cerraste la app; después se borra.

## Terceros
Para analizar, el servidor envía datos públicos del mercado a Google Gemini. En el plan gratuito, Google puede usar ese contenido para mejorar sus productos. Los datos de mercado vienen de fuentes públicas (Yahoo Finance, SEC EDGAR, Polymarket).

## Aviso
Los análisis los genera una IA y pueden equivocarse. No son asesoría financiera.
